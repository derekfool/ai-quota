# App icon

AppIcon.png is the user-approved gray-and-white anime cat holding an AI conversation ticket, generated with OpenAI image generation on 2026-09-13 using a user-provided cat photo as a visual reference. The owner states that the reference was also generated with ChatGPT; see ../ASSET_PROVENANCE.md.

AppIcon.icns contains standard macOS 16, 32, 128, 256, and 512 point representations at 1x and 2x, resized with sips and packaged as PNG representations in an ICNS container. build.sh copies it into the app bundle; Info.plist selects it. Keep the PNG as the source for future exports.
