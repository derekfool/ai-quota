# Security policy

Use [GitHub Private Vulnerability Reporting](https://github.com/derekfool/ai-quota/security/advisories/new), or the repository Security tab → Report a vulnerability. Private reporting is enabled. Do not open a public issue with exploit details or account data.

Include affected versions, reproduction steps, impact and a minimal synthetic example. Never include live cookies, tokens, passwords or private account dumps. Only the current main branch is maintained; there is no promised response-time SLA.
