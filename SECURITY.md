# Security policy

The owner has selected GitHub Private Vulnerability Reporting. It must be enabled and verified when the repository is made public; it is not yet available on this private preparation repository. Once enabled, use the repository Security tab → Report a vulnerability. Do not open a public issue with exploit details or account data.

Include affected versions, reproduction steps, impact and a minimal synthetic example. Never include live cookies, tokens, passwords or private account dumps. Only the current main branch is maintained; there is no promised response-time SLA.
