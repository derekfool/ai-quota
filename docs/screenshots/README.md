# README interface previews

Generated on 2026-09-13 from the application views at c6d8da2 with an isolated temporary renderer. All quota values and history are synthetic; no account fetch or saved history was used.

The renderer uses DashboardView/MetricView and QuotaHistory/QuotaForecast, fixes time for deterministic labels, and expands the Codex weekly chart in the trend variants. The live NSVisualEffectView is replaced by a static gradient. The closed native Menu is represented by its ellipsis symbol because SwiftUI ImageRenderer cannot render native menu controls. These are interface previews, not evidence of live-account behavior or physical window rendering.

English and Chinese each include an overview and a trend/collapsed-card variant. The production app code and runtime data are unchanged.
